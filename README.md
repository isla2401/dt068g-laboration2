# DT068G - Laboration 2

## Tillgänglig design & typografi

Syftet med denna uppgift var att skapa en enkel och tillgänglig webbplats utifrån en färdig uppsättning text och bilder.

### Krav för uppgiften:
- HTML-koden ska struktureras korrekt med lämpliga element för semantik.
- Lägg till lämpliga rubriker, med en logisk rubrikstruktur i HTML.
- Infoga bilderna där det är lämpligt (alla bilder ska användas).
- Skriv relevanta alt-texter till bilderna.
- Använd punktlistor för att lyfta fram vissa delar ur texten.
- Delar i texten så som ingresser och citat ska särskiljas från övrig text.
- Tillräckliga kontraster.
- Dynamiska mått ska användas för text i stilmallen.
- Använd lämplig radlängd.
- En extern tjänst för teckensnitt ska användas, till exempel Google Fonts.
- Webbplatsen är responsiv och fungerar för olika enheter.
